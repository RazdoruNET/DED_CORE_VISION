# Протокол модуля с DED CORE V4

Модуль — клиент точки доступа ядра. Своей сети в рабочем режиме он не
поднимает: ядро уже рассылает телеметрию всем подключённым клиентам WebSocket
на порту 81.

## 1. Кадр телеметрии

```json
{
  "event": "message",
  "data": {
    "card": 0,
    "select_cart": 1,
    "rpm": 3500,
    "max_rpm": 12000,
    "type": 2,
    "throttle": 18,
    "init_angle": 6,
    "aa": 1,
    "micros": 12345678,
    "servo": 1,
    "servo_position": 120,
    "servo_type": 0,
    "servo_rpm": 0,
    "servo_percent": 40,
    "angles": [[1000, 12.0, 0, 0, 0], "…"]
  }
}
```

| Поле | Использование |
|---|---|
| `card` | активная карта, 0…2 → кнопки 1/2/3 |
| `rpm`, `max_rpm` | тахометр, MAX, большие обороты |
| `angles[i][0]` | обороты точки карты |
| `angles[i][1]` | угол опережения точки карты |
| `type` | 0 / 1 / 2 → 7 / 12 / 22 точки |
| `throttle` | полоса POWER, % |
| `init_angle` | угол на первом обороте — верхняя граница графика |
| `micros` | метка времени ядра |
| `servo*` | зарезервировано под индикацию привода |

Свежесть кадра — 3 секунды. Дольше — модуль считает связь потерянной,
показывает «DED BOX OFFLINE» и гасит приборку.

## 2. Сопряжение

1. Владелец открывает окно из приложения: `POST /module/pair/start` с
   `X-Device-Key`.
2. Ядро на 90 секунд поднимает открытую сеть `DED_PAIR_<4 hex>`.
3. Модуль сканирует эфир, подключается к ней и запрашивает
   `GET http://192.168.4.1/module/pair`.
4. Ядро отвечает:

```json
{
  "event": "module_pair",
  "data": {
    "ssid": "DED_BOX_V4",
    "pass": "уникальный пароль блока",
    "host": "192.168.4.1",
    "port": 81,
    "token": "<токен модуля>",
    "fw": "4.0.16"
  }
}
```

5. Модуль сохраняет параметры и токен в NVS и перезагружается.

Автоматическое пересопряжение ограничено сохранённым BSSID точки сопряжения:
чужая открытая `DED_PAIR_*` не уведёт настроенный модуль на поддельный блок.

## 3. Доверенный модуль

После подключения:

```json
{"event":"module_hello","data":{"mac":"AA:BB:CC:DD:EE:FF","fw":"1.0.0","token":"<токен>"}}
```

Ответ: `{"event":"module_hello","data":{"trusted":1}}`.

Смена параметров точки доступа приходит доверенным модулям кадром:

```json
{"event":"module_credentials","data":{"ssid":"DED_BOX_V4","pass":"новый пароль","host":"192.168.4.1","port":81}}
```

Модуль сохраняет их и переподключается без нового сопряжения.

## 4. Команды модуля

| Команда | Назначение |
|---|---|
| `{"event":"cart","data":{"cart":1..3}}` | переключить активную карту на ядре |

В игре кнопки 1/2/3 меняют **локальную** полосу игрока и карту ядра не
переключают.

## 5. Портал настройки

Точка доступа `DED_CORE_VISION`, страница `http://192.168.5.1/`.

| Маршрут | Назначение |
|---|---|
| `GET /` | состояние и настройки |
| `POST /save` | сохранить `ssid`, `pass`, `host`, `port` |
| `GET /pair` | запустить поиск сети сопряжения |
| `GET /display/test` | проверить панель цветными полосами |
| `POST /reset` | сбросить настройки ядра |
| `POST /close` | закрыть портал |
| `GET /update` | обновление прошивки (логин `admin`, пароль из лога) |
| `GET /status.json` | состояние в JSON |

`status.json`:

```json
{
  "event": "status",
  "data": {
    "fw": "1.0.0",
    "link": 1,
    "core_ssid": "DED_BOX_V4",
    "core_host": "192.168.4.1",
    "card": 0,
    "rpm": 3500,
    "gear": 2,
    "screen": 0,
    "best": 45800,
    "frames": 15230
  }
}
```
